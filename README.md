## 🌟 Overview

**SkillForge AI** is an intelligent, agentic learning platform designed to bridge the gap between a learner's current capabilities and evolving industry standards. 

Traditional learning paths are rigid and linear. SkillForge AI replaces static curricula with a **dynamic 4-agent collaborative mesh** that continuously monitors learner telemetry, detects conceptual gaps, evaluates diagnostic assessments, and automatically injects self-healing remedial modules in real time.

---

## 🤖 The 4-Agent Autonomous Mesh

SkillForge AI is powered by four specialized, cooperating agents:

1. **Profiler & Gap Agent**:
   - Computes granular delta scores against role benchmarks (Full Stack Developer, AI/ML Engineer, Backend Engineer, Cybersecurity Analyst).
   - Recalculates role readiness percentage upon every telemetry update or career goal pivot.

2. **Curriculum Architect**:
   - Constructs ordered, prerequisite-aware learning paths.
   - Pairs each module with curated courses, labs, and interactive sandboxes.

3. **Assessment Evaluator**:
   - Generates and grades technical micro-assessments based on domain question banks.
   - Enforces a **60% mastery threshold** before unlocking downstream curriculum stages.

4. **AI Mentor Orchestrator**:
   - Serves as the adaptive feedback controller.
   - When a diagnostic score falls below 60%, it intervenes, halts downstream progression, and instructs the Curriculum Architect to inject a targeted **Remedial Sandbox Lab** directly into the roadmap.

## ✨ Key Features

- **🎯 Interactive Role Switching**: Switch targets between Full Stack, Backend, AI/ML, and Cybersecurity with instant roadmap regeneration.
- **📊 Real-Time Skill-Gap Radar**: Visual comparative bar charts displaying current learner proficiency vs. industry benchmark requirements.
- **⚡ One-Click Remedial Simulation**: Built-in *"Simulate Low Quiz Score"* button allowing evaluators to witness the live adaptive self-healing loop in action.
- **📝 Live Multi-Agent Stream**: Real-time console log streaming agent-to-agent negotiations, gap analyses, and remedial injections with visual heartbeat pulses.
- **💬 AI Mentor Chat Interface**: Interactive conversational agent providing contextual guidance, gap explanations, and career transition advice.
- **🌙 Cyberpunk Dark Aesthetic**: Built with custom Tailwind CSS slate-950/indigo dark palette, frosted-glass headers, and micro-interactions.

## 🚀 Quick Start Guide

### Prerequisites
- Node.js (v18.0 or higher recommended)
- npm (comes bundled with Node.js)

### 1. Clone the Repository
```bash
git clone https://github.com/elangokumar0000/skillforge-ai.git
cd skillforge-ai
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open **http://localhost:5173** in your browser to view the application.

### 4. Build for Production
```bash
npm run build
```

## 🌐 Free One-Click Deployment

### Deploy to Vercel (Recommended)
1. Fork or push this repository to your GitHub account.
2. Sign in to **[Vercel](https://vercel.com/)** and click **Add New Project**.
3. Import `skillforge-ai`.
4. Click **Deploy** (Vite settings are pre-configured automatically).

### Deploy to Netlify
1. Run `npm run build` locally.
2. Go to **[Netlify Drop](https://app.netlify.com/drop)** and drag-and-drop the generated `dist/` folder.
